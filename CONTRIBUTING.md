# Contributing to TruckSave Cloud

Contributions are welcome under the MIT license. Open an issue describing the problem or feature, then submit a focused pull request. Do not include Google OAuth client credentials, user save files, personal data, or tokens. Test changes using a disposable ETS2 profile and document any Windows and Google Drive behaviors you verified. Avoid changing restore/deletion logic without automated tests and a rollback plan. Report security vulnerabilities privately according to SECURITY.md rather than posting exploit details in public issues.
